# Electricity Bill Management System

A static front-end project for an electricity bill management system with dashboard, billing, customer, meter, and payment modules.

## Run locally

From the project folder, start a local server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```

## Project structure

- `admin_dashboard/`
- `bill_generation_invoice/`
- `customer_management/`
- `customer_portal_consumption/`
- `meter_management/`
- `meter_readings/`
- `payments_management/`
- `login_role_switch_1/`
- `login_role_switch_2/`
- `urja_command_grid/`

## Notes

This project is a front-end mockup/static HTML prototype for an electricity billing platform.
